## Air Quality in Istanbul: Spatial, Seasonal, and Weekly Patterns

This project aims to examine how PM10 concentrations vary across selected air quality monitoring stations in Istanbul. Under the theme “Cities We Live In,” we will investigate spatial differences, seasonal patterns, and weekday–weekend differences. Our planned source is the Istanbul Metropolitan Municipality’s air quality monitoring system; access to historical measurements is currently awaiting confirmation.

We plan to select three to five monitoring stations and one complete calendar year based on data availability and completeness. If hourly observations are obtained, we will aggregate them into daily averages using a documented minimum data coverage rule. Data preparation will include checking timestamps, duplicate records, missing observations, measurement units, and potentially invalid values. Missing measurements will not be treated as zero.

The analysis will compare daily PM10 distributions across stations, summarize seasonal variation, and examine weekday–weekend differences within seasons. Planned visualizations include station comparison plots, monthly trends, and seasonal comparisons. These analyses will describe observed patterns rather than establish their causes. Individual stations will not be assumed to represent entire districts.

The final repository will document data sources, processing decisions, reproducible Python scripts, and visual findings. No empirical findings are reported at this stage.
